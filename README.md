# Project Name
**lecture-scheduler_assignment**

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB

### Project Details

- **Project Description**:  
     This project is a lecture scheduling system where admin users can manage courses, schedule lectures, and assign instructors. Instructors can view their assigned lectures and course details. It provides a user-friendly interface for managing lecture schedules efficiently.

- Technologies Used:  
  This project is built using the following technologies:
  - **React.js** for building the frontend.
  - **Node.js** with **Express.js** for the backend API.
  - **MongoDB** for storing lecture schedules, courses, and user data.
